# console-todo-list
TO-DO LIST APPLICATION
This is a basic Python console application that lets you add,view,update and delete tasks.
All tasks are stored in a text file(tasks.txt) using Python's open() function

HOW TO RUN
1.Save the python file(todo.py)
2.Run it using:
    py todo.py
3.A file named tasks.txt will be created in the same folder to store your tasks.

FEATURES
i.Add tasks
ii.View tasks
iii.Update tasks
iv.Delete tasks
v.stores tasks in a text file
